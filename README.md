# PRO100TOP

Стартовый сайт PRO100TOP.

## Демо-доступ к админке
Логин: `admin`
Пароль: `CHANGE_ME_NOW`

**Важно:** это только демонстрационная локальная админка. Не публикуйте её в интернете с этим паролем. Для настоящих админских прав нужен сервер, база данных и безопасная авторизация с хешированием пароля.

## Запуск
Откройте `index.html` в браузере. Админка находится по адресу `admin.html`.

## Публикация
Для реального запуска нужно разместить файлы на хостинге и подключить домен. После этого можно заменить демо-админку на полноценную серверную систему пользователей.
